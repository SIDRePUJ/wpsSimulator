# Goal selection (model description)

At each deliberation, the household evaluates its library of goals. Each goal has a name, a priority level (1 is the highest priority, larger numbers are lower priorities), a Boolean activation, a base contribution c in (0, 1], and an emotional susceptibility lambda in [0, 1]. Deliberation is lexicographic: only the highest-priority level that contains at least one active goal is considered, and inactive goals are ignored. Within that level, each active goal receives the modulated contribution (1 - lambda) * c + lambda * phi, where phi in [0, 1] is the affective contribution, and the goal with the largest modulated contribution is selected; ties are broken in favour of the goal that appears first in the list. In the non-affective baseline (emotions disabled), lambda is taken as 0 for every goal, so the base contribution alone decides. If no goal is active, no goal is selected (None). Goals are given as dictionaries with keys "name", "level", "active", "c", and "lam", and the selection returns the name of the selected goal.
